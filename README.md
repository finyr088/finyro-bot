# Финуро — Telegram-бот + мини-приложение для курса финграмотности

Telegram-бот с админ-панелью и Telegram Mini App для продажи и ведения курса
подготовки к отборочным этапам по финансовой грамотности. Оплата подтверждается
вручную, доступ к материалам (вебинары, теория, тесты) открывается поэтапно.

Реализовано по [техническому заданию](#соответствие-тз) v1.0.

## Стек

| Слой | Технология |
|------|-----------|
| Бот | Python + [aiogram 3](https://aiogram.dev) (long polling) |
| API + раздача мини-аппа | FastAPI + Uvicorn |
| Мини-приложение | Vanilla HTML/CSS/JS (без сборки), плеер [hls.js](https://github.com/video-dev/hls.js) |
| База данных | SQLite (по умолчанию) → легко на PostgreSQL |
| Авторизация мини-аппа | Telegram WebApp `initData` (HMAC) + JWT |

Всё работает в **одном процессе**: FastAPI отдаёт API и мини-апп, а бот
крутится рядом в режиме polling — удобно и дёшево разворачивать.

## Возможности

**Бот (ученик):** приветствие с ценой, оплата → приём скриншота чека, статус
заявки, кнопка запуска мини-аппа после подтверждения, поддержка.

**Бот (админ-панель, вход по Telegram ID):** заявки на оплату с подтверждением/
отклонением в один клик, список учеников с выдачей/отзывом доступа, добавление и
публикация вебинаров и тем теории (поэтапно), результаты тестов, обращения в
поддержку с ответом, рассылка активным ученикам, лог действий администратора.

**Мини-приложение:** Главная с блоком «Продолжить просмотр», список вебинаров с
защищённым HLS-плеером и **динамическим водяным знаком** (имя + ID ученика),
тесты с автопроверкой, теория, личный кабинет (прогресс + поддержка).

## Быстрый старт (локально)

Нужен Python 3.11+.

```bash
# 1. Настройки
cp .env.example .env
# впишите BOT_TOKEN (от @BotFather) и ADMIN_IDS (ваш Telegram ID)

# 2. Запуск
./run.sh
```

Скрипт создаст виртуальное окружение, поставит зависимости и поднимет сервис на
`http://localhost:8080`. При первом старте база наполняется демо-контентом
(2 вебинара, тема теории, тест на 5 вопросов).

### Открыть мини-апп в браузере без Telegram (для разработки)

Поставьте `DEV_MODE=1` в `.env` — тогда мини-апп на `http://localhost:8080`
авторизует тестового пользователя без Telegram. Доступ к материалам выдайте так:

```bash
sqlite3 finyro.db "UPDATE users SET access_active=1 WHERE telegram_id=999000999;"
```

> ⚠️ `DEV_MODE` отключает проверку подписи — **никогда не включайте в проде.**

## Настройка бота в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите **BOT_TOKEN**.
2. Узнайте свой **Telegram ID** (например, у [@userinfobot](https://t.me/userinfobot)) — это `ADMIN_IDS`.
3. Разверните сервис на HTTPS-домене (см. ниже) и укажите его в `MINIAPP_URL`.
4. В @BotFather → *Bot Settings → Menu Button* (или в коде уже есть кнопка) укажите тот же `MINIAPP_URL`.
5. Напишите боту `/start` — как админ, откройте панель командой `/admin`.

> Кнопка запуска мини-аппа появляется только при `MINIAPP_URL`, начинающемся с
> `https://` (требование Telegram). Локально по http кнопки не будет — это норма.

## Деплой

Мини-приложению нужен публичный **HTTPS**. Подойдёт любой VPS или облако.

### Вариант A. Docker (любой сервер)

```bash
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, MINIAPP_URL, SECRET_KEY
docker compose up -d --build
```

За HTTPS отвечает reverse-proxy (Caddy/Nginx/Traefik) перед контейнером на :8080.
Самый быстрый способ получить сертификат — Caddy с автоматическим Let's Encrypt.

### Вариант B. Railway / Render / любой PaaS

- Подключите репозиторий. Платформа сама соберёт по `Dockerfile` (или `Procfile`).
- Задайте переменные окружения из `.env.example`.
- `MINIAPP_URL` = публичный URL, который выдаст платформа.
- HTTPS такие платформы дают из коробки.

### PostgreSQL (по желанию, для масштаба)

```bash
pip install "asyncpg"
# в .env:
DATABASE_URL=postgresql+asyncpg://user:pass@host:5432/finyro
```

Таблицы создаются автоматически при старте.

## Переменные окружения

Полный список с комментариями — в [`.env.example`](.env.example). Главное:
`BOT_TOKEN`, `ADMIN_IDS`, `MINIAPP_URL`, `SECRET_KEY`, `PAY_REQUISITES`,
`COURSE_PRICE`, `ACCESS_DAYS` (0 = бессрочно), `DATABASE_URL`.

```

  main.py           точка входа: FastAPI + запуск бота, раздача мини-аппа
  config.py         настройки из окружения

  services.py       бизнес-логика (доступ, оплаты, прогресс, «продолжить»)

```

## Защита видео

Полностью исключить запись экрана нельзя (об этом честно сказано в ТЗ). Реализован
комплекс мер по снижению утечек: видео отдаётся стримом (HLS) без прямой
скачиваемой ссылки, плеер без кнопки «скачать» (`controlsList=nodownload`, без
PiP, отключено контекстное меню), **динамический водяной знак** с именем и ID
ученика поверх видео, ручной отзыв доступа админом. Рекомендуется дополнительно
включить content protection в самом видеохостинге и прописать условия в оферте.

## Соответствие ТЗ

Этапы 1–5 из ТЗ покрыты: заявки на оплату и ручная выдача (1), кабинет и вебинары
со стрим-защитой (2), тестирование (3), теория (4), поддержка/рассылки/водяные
знаки (5). Брендинг «Финуро» — палитра фиолет/лайм и шрифт Manrope — применён во
всём мини-приложении.

### Допущения (открытые вопросы раздела 13 ТЗ)

- Оплата — **вручную** (перевод + скриншот). Архитектура готова к добавлению эквайринга.
- Доступ по умолчанию **бессрочный**; ограничение по времени включается через `ACCESS_DAYS`.
- **Один тариф** (структура БД позволяет добавить тарифы/потоки).
- Общение с учениками — **через администратора** (без группового чата).

Эти значения меняются переменными окружения или небольшим расширением моделей.
